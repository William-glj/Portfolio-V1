# Portafolio

Portafolio personal desarrollado con React y Vite. Presenta la trayectoria, formación, certificaciones, proyectos y tecnologías de Guillermo Lemos Jiménez.

## Desarrollo

```sh
npm install
npm run dev
```

## Validación y producción

```sh
npm run lint
npm run build
npm run preview
```

El contenido y los estilos de cada sección están en `src/sections` y `src/styles`. Las imágenes, iconos y el currículum se encuentran en `src/assets`.
